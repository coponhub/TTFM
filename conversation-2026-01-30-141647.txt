  ## 1. ラベル等価比較演算子 (`:==` → `:=`)                                 
                                                                            
  ### 設計仕様 (QUERY.md:71)                                                
  ```                                                                       
  ラベル比較演算子: :=, :^, :^=, :>, :>=, :<, :<=                           
  ```                                                                       
                                                                            
  ### 修正                                                                  
                                                                            
  **`query.pest`**:                                                         
  ```pest                                                                   
  // ラベル比較用（等価は "=" ）                                            
  label_basic_op = @{ "=" | "^=" | "<=" | ">=" | "^" | ">" | "<" }          
                                                                            
  // スカラー比較用（等価は "==" ）                                         
  scalar_basic_op = @{ "==" | "^=" | "<=" | ">=" | "^" | ">" | "<" }        
  ```                                                                       
                                                                            
  **`parser.rs`**:                                                          
  - ラベル比較: `"="` → `BasicOp::Eq`                                       
  - スカラー比較: `"=="` → `BasicOp::Eq`

  ## 2. 密着ラベル比較のスペース不可


  ## 3. 密着比較の演算子（`==` 削除）                                       
                                                                            
  ### 設計仕様 (QUERY.md:86, 91)                                            
  ```                                                                       
  比較演算子: ^ (不一致), >, >=, <, <= (大小比較)                           
  イコール演算子(=)は存在しない。TypedTagをそのまま書いた場合と同じ結果とな 
  るため                                                                    
  ```                                                                       
                                                                            
  ### 修正                                                                  
  ```pest                                                                   
  // 密着比較用 - "=" や "==" は無し                                        
  stuck_basic_op = @{ "^=" | "<=" | ">=" | "^" | ">" | "<" }                
  ```

  ## 4. 算術演算のスペース必須

  ```                                                                       
  1*2   → 算術演算ではない                                                  
  1 * 2 → OK                                                                
  ```                                                                       
                                                                            
  ### 修正

  ```pest                                                                   
  arith_op = @{ WHITESPACE+ ~ ("+" | "-" | "*" | "/" | "%") ~ WHITESPACE+ } 
  ```
